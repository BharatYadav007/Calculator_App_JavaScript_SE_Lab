# Advanced Calculator

A Node.js command-line calculator built on the existing arithmetic modules.

## Features

- Addition, subtraction, multiplication, division
- Power
- Percentage
- Modulo
- Square root and cube root
- Factorial
- Base-10 logarithm and natural logarithm
- Sine, cosine and tangent in degrees
- Absolute value
- Reciprocal
- Degree/radian conversion
- Calculation history

## Run

```bash
npm start
```

or

```bash
node calculator.js
```
